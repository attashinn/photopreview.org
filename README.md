## Overview

- **Public Site**: Fast, image-led editorial portfolio covering corporate event photography, diplomatic summits, live concert stages, fashion runway, and commercial campaigns.
- **Client Booking**: Real-time calendar scheduler with instant WhatsApp confirmation.
- **Studio Command Console (`/admin`)**: Private management dashboard for shoot calendar scheduling, date blocking, media portfolio uploads, and accounts/loss ledger tracking.

## Development

Run locally using Node.js:

```sh
npm install
npm run dev
```

Build for production:

```sh
npm run build
```
